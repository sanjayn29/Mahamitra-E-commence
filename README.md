# 🛒 Mahamitra

**Mahamitra** is a modern eCommerce web application designed to provide a smooth and reliable online shopping experience.  
The platform is built with a **modern full-stack architecture** using React, TypeScript, and Supabase — enabling fast performance, secure authentication, scalable backend services, and an AI-powered shopping assistant.

🌐 **Live Website:** https://www.mahamitra.app/

---

## 🚀 Features

- 🛍️ Product browsing, filtering & shopping experience
- 🔐 Secure user authentication (Sign up / Login)
- 🧾 Order management & order history
- 💳 Online payment integration via Razorpay
- 🤖 AI-powered shopping assistant (Groq AI)
- 🎟️ Discount coupon & promo code system
- 💰 Customer wallet & top-up system
- 📦 Inventory & variant management (admin)
- 📊 Admin analytics & financial reports
- ⭐ Product reviews & ratings
- 📧 Email notifications via EmailJS
- 🏠 Address book management
- 📄 PDF receipt generation
- ⚡ Fast and scalable backend using Supabase Edge Functions
- 📱 Fully responsive design for desktop and mobile

---

## 🧑‍💻 Tech Stack

### Frontend
- React 18
- TypeScript
- Tailwind CSS
- Shadcn UI (Radix UI)
- React Router DOM
- React Hook Form + Zod
- Recharts (Analytics)
- Lucide React (Icons)

### Backend & Database
- Supabase (PostgreSQL)
- Supabase Auth
- Supabase Edge Functions (Deno)

### Integrations
- **Razorpay** — Payment Gateway
- **Groq AI** — AI Chatbot (via Supabase Edge Function)
- **EmailJS** — Contact Form Email Notifications
- **jsPDF + html2canvas** — PDF Receipt Generation

---

## 🔒 Security & Performance

- Secure authentication handled by **Supabase Auth**
- Serverless backend logic via **Supabase Edge Functions**
- Secure payment transactions via **Razorpay**
- AI API key safely stored as **server-side Edge Function secret**
- Fast client-side rendering with **React + Vite**
